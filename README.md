# 🚀 plearning

Guía interactiva estilo NestJS con animaciones para aprender Deploy, CI/CD, Nginx y Linux. Framer Motion, sidebar colapsable y código copiable.

## 🔗 Temas cubiertos

**Deploy:** Intro · Plataformas · Frontend · Backend · Dominios · SSL · Variables · Monitoreo

**CI/CD:** Intro · GitHub Actions · Pipeline · Testing · Docker · Tips

**Nginx:** Intro · Configuración · Reverse Proxy · SSL Certbot

**Linux:** Esencial · Server Setup · Seguridad · Deploy Completo

## 🛠️ Tecnologías

- **React 18** — Biblioteca de UI
- **Tailwind CSS v4** — Estilos utility-first
- **Framer Motion** — Animaciones
- **Vite** — Build tool
- **Lucide React** — Iconos
